OpenTrack WXR (for XrAPI) V1.0
-------------------------------------
Thanks to GmoLargey for both the idea of adding XrAPI support to OpenTrack and testing
Thanks to Luboš for his support and development of WinlatorXR!

Fork by Bigelowed, any code added is available under LGPL V3 so you can add XrAPI support to your programs too!

Recommended usage is:

1. Extract to a folder like "Downloads > wxr"
2. Add it as a secondary executable to your target game shortcut (eg: D:/wxr/opentrack.exe)
3. Add a 3 to 5 second delay to starting the secondary executable

NOTE: If the game you are trying to play isn't accepting input, use the Right Thumbstick Click to open the pop-up menu, then select the Task Manager icon, then select your game and click "Switch To"

4. Enjoy!
